# NxNative-Mobile
On-device Nintendo Switch game compilation for iOS using NxNative.

**Status:** early work in progress. Beta coming soon.

## Install (AltStore)
1. Download `NxNative-unsigned.ipa` from the latest [Release](../../releases).
2. Open it in AltStore (share sheet, "Open in AltStore") and let it sign and install.
3. Free Apple IDs: apps expire after 7 days and are limited to a few active sideloaded apps.

## Use only your own content
Use only games you dumped yourself from your own hardware, or open-source and homebrew titles. This project does not include or distribute keys, firmware, or game files, and none will be provided.

## Reporting bugs
Open an issue with your device model, iOS version, AltStore version, the build number (Release name), and logs if available.
